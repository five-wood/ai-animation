## 已知边界与后续

- 模型准备前的 3D 方向可视化未实现；对话框明确告知参考图在准备阶段后生成。
- 当前仍沿用后端完整 prepare→gen→train→exam 流程；预览确认后分阶段启动需要后续服务端支持。
- 任务中心只覆盖 Web 队列记录，不能完整枚举命令行直接发起的训练。外部训练仍可在训练曲线/日志中查看，任务计数 0 不代表 GPU 没有外部任务。
- 未新增完整产物版本管理、自动剩余时间估算、CLI 任务接管、人工验收状态；不作这些能力的承诺。
- 后端 `/api/projects` 会扫描训练元数据，较慢时显示加载状态；性能优化留待后续，不在训练中热改后端。
