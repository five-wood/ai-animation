# xiyi2 抖动量化诊断（只读）

## 结论

1. **抖动已存在于求解旋转中，不是此次 Blender 关键点导出引入。** `motion.npz` 的 `kp` 与 `blender_kp3d.json` 同帧同点的位置 RMS 误差 **1.60×10⁻⁷** 世界单位，最大 **5.74×10⁻⁷**（体长尺度的 **0.00002197%**）；零帧偏移显著最优。quat/eul 一致、四元数连续，没有符号跳变。
2. **局部与全局旋转都含高频；不能只怪全局，也不能只按局部角加速度最大骨骼滤波。** 全局 G 角加速度 RMS **413.1°/s²**，角速度谱 ≥3Hz 占 **79.73%**、≥6Hz 占 **49.60%**。局部角加速度最大的是 **knee.L、tail4、tail3、tail2**，但传播到多个末端位置的敏感度最大的是 **spine1、spine2 与 G**。
3. **存在明显旋转补偿/相消。** 只对 G 做诊断性 3Hz 低通，整体关键点 ≥3Hz 位置能量反而变为原来的 **2.02倍**；只平滑所有局部为 **1.65倍**；单独 spine1 / spine2 为 **2.70 / 2.37倍**。联合平滑 G 和所有局部才降到 **0.0227倍**。这是参数分解中的相消证据，不是允许直接修改结果的依据。
4. **2D 观测中最明显的异常源是 front 视图的尾端，此外左踝、side 左腕值得复核。** front 的 tail4 ≥3Hz 轨迹 RMS **17.38px**，side 同点只有 **0.73px**；front 的 tail3 为 **9.24px**。原视频正面尾巴高度遮挡/缩短，与低置信、跳点相符。稀疏 LK 仅提供旁证，不能把它当遮挡关节 GT。
5. 原有双视图一致性检查 0/121 坏帧并不意味着旋转平滑；它主要检查空间/两视图一致性。没有动作 GT，**本报告不宣称低通后的幅度更真实，也不宣称现有输出动作幅度保真**。

## 数据、约定和方法

- 远程：`animsrv:/data/video2rig/projects/lizard/out/xiyi2`；原视频 `/data/video2rig/videos/xiyi2.mp4`。
- 原视频实测 **1280×720、24fps、121帧**，帧时间跨度 0–5.000s，容器时长 5.04167s；自动 split=642。
- rig：22 骨、17 active、28 关键点；rig.size=**2.6133360267** 世界单位。没有推断物理米制。
- 读取 `reading.npz` 的 uv / uv_raw / uv_reader / conf / conf_fit / X / X_fit / res；读取 `motion.npz` 的 G / quat / eul / kp / fps；逐点对比 Blender 求值位置。
- G 是世界坐标全局变换，绕 rig.center 旋转；quat 是全部骨骼的局部 **wxyz** 四元数，eul 仅 active 骨、Blender XYZ 弧度。使用独立 NumPy FK 复核，不导入核心代码。
- 角速度：固定表达坐标内 `log(R[t+1] R[t]^T) × fps` 的 SO(3) 向量，单位 °/s；角加速度为该向量逐帧差分 ×fps，°/s²。不是对四元数分量或欧拉角直接求导。world 旋转用固定世界坐标，local 用各骨旋转前的局部坐标。
- 频谱：线性去趋势、Hann 窗、单边 periodogram，向量分量能量求和，排除 DC；分别统计 ≥3 / ≥4 / ≥6Hz 至 Nyquist 12Hz。姿态轨迹谱与角速度谱分母不同，不能混用。
- 121帧姿态/位置谱分辨率约 **0.19835Hz**（≥3Hz 的首个实际 bin 是 3.17355Hz）；120样本角速度谱为 0.2Hz。短片、窗函数与低通边界会影响阈值附近统计，不能把 3Hz 当物理真伪边界。
- 位置 HF RMS 在所有关键点/视图等权平均后开方；“%size”表示除以 rig.size×100。给出的角度 HF RMS 是旋转相对首帧的 SO(3) log 轨迹谱。
- 所有峰值帧号均 **从0起算**；Blender 帧号加1。全121帧均纳入计算，不排除端点。

## 5. 哪些骨头“贡献最大”：必须分清量

局部角加速度最大不等于末端位置贡献最大。用仅在内存中执行的3Hz Butterworth四阶零相位低通（旋转先转SO(3) log）进行敏感度实验；输出只写 `/tmp`，不改 motion。下表“移除分量 HF”是原FK位置减去该反事实FK的位置差的≥3Hz RMS，跨28点平均并按size归一化。

| 诊断性低通分量 | 被改变位置的≥3Hz RMS %size | 低通后整体≥3Hz位置能量 / 原始 |
|---|---:|---:|
| 所有局部 | 0.13898 | **1.648** |
| **spine1** | **0.13188** | **2.697** |
| 所有 G（旋转+中心平移） | 0.12695 | **2.024** |
| **spine2** | **0.12165** | **2.371** |
| 仅 G 旋转，中心平移保持原始 | **0.11168** | **1.993** |
| tail2 | 0.08840 | 1.461 |
| tail1 | 0.07689 | 1.404 |
| chest | 0.07460 | 1.423 |
| tail3 | 0.07217 | 1.717 |
| 仅中心平移 | 0.06720 | 1.116 |
| knee.L | 0.03443 | 0.959 |
| tail4 | 0.02290 | 1.016 |
| **G与所有局部联合** | 0.09275 | **0.0227** |

- spine1/spine2 的局部角度高频虽然不是最大，但会影响整条上半身链；tail2/tail1影响多个尾段；tail4只直接改变一个尾端，故在“全部关键点平均”尺度下敏感度较小。
- 单独低通后多数指标反升，表示多级旋转原本存在抵消。对世界骨骼角速度做3Hz高通后，G与去G剩余角速度的余弦约 spine1 **-0.546**、spine2 **-0.606**、chest **-0.628**、neck **-0.600**，也与负相关补偿吻合。
- **这些数值不具可加性，不应写成贡献占比或训练改动收益。** Butterworth的频带响应、序列边界、固定rest与实际拟合的耦合均影响反事实；这里只用于发现敏感方向及不宜独立滤波的证据。

## 7. 建议（未实施）

1. **先做有针对性的观测复核，不改训练和阈值。** 按上面的帧号逐帧叠加 front尾链、front左踝、side左腕的 uv/conf/投影与局部图像；人工只记录可见性/跳点/标签疑似问题，不给遮挡点编造GT。
2. **若以后允许修改求解，优先讨论联合时域约束和可观测性，而非独立后滤波。** 在SO(3)上共同约束 G 和局部角速度/加速度，结合世界/屏幕末端位置约束与contact条件；避免在 G 和 spine 的抵消关系上单独施加强低通。当前代码已有世界kp二阶差分与局部Euler二阶差分项，但没有显式 G 旋转平滑项，这与全局补偿高频现象相容；不能仅凭本实验断言唯一原因。
3. **弱可见尾部与高置信错误需要分开处理。** front尾端低conf且跳跃，单看平均conf会被side较高值掩盖；左踝conf并不低但残差大，说明置信不等于位置正确。未来可评估按视图/可见性与鲁棒残差建模，但本轮不改阈值、不重训、不重求解。
4. **先建立不依赖GT的检查集合，再评估任何平滑。** 除旋转高频外，联合看重投影、接触脚滑、相位延迟、首尾边界与低频动作形状；零相位低通是离线诊断，不能据此推荐实时延迟表现。若要声称幅度保真，需人工可见点标注或独立GT/合成真值试验；不能把未滤波输出或低通输出当GT。
5. **导出层无需因本次结果贸然改动。** 如某外部软件仍显示不同抖动，再单独执行FBX/GLB/BVH回读与亚帧插值验证；本轮只证实 Blender关键点与motion逐帧匹配。
