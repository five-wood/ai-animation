# soft-clean 柔光无地面投影配置：实测记录

2026-11-03。新项目 lizard_clean；原 lizard、参考图、识别器与所有动画结果未覆盖。

## 改动

- 三个大面积光源+适量环境填充取代两个方向性SUN，保留角色自身明暗、纹理、颜色。
- 参考图不放置地面接收体/shadow catcher，因此没有地面投影；不是把整张图阈值化或变剪影。
- 用 geometry-from 复用原项目rig.json及camera参数，22骨、17可动骨、28关键点逐项一致。
- 训练随机渲染读取同一个studio visual_profile，小幅随机柔光。训练合成中性灰背景，不额外添加地面阴影与尘土；保留前景颜色和画质增强。
- 考试视频背景也不加阴影，网页训练样本增强遵循对应profile。
- 新项目网页默认选soft-clean，CLI默认legacy保持旧兼容。已有项目无字段时legacy。

## 验证

- 3000姿势×2视图，10worker约64s；20轮训练25.5min；新best.pt约338MiB。
- 6项profile测试通过。默认legacy与冻结旧实现32seed train/val逐位及RNG相同；soft-clean不调用add_shadow/add_dust，透明区背景中性；标签变换测试通过。
- 参考图主体下方alpha严格0，无shadow-catcher输出。角色本体明暗保留。
- 全部训练样本FK相对尺寸最大误差3.38e-6，投影标签最大误差2.27e-13px；相机/rig与旧项目完全相同。
- 网页lizard_clean项目、reference下载、训练图、20轮日志和考试报告均HTTP可用；已在Chrome检查profile提示及1280像素参考图加载。
