# 教学视频思路整理：AI Can Now Animate Any Monster

来源：`Videos/AI Can Now Animate Any Monster. Opus 5.5 Built the Tool [AS92HYsEBqo].mp4`（9 分 19 秒，英文字幕 `.en-US.srt`）。
整理时间：2026-11-04。关键画面截图：`video2rig/results/tutorial_frames/`（每张 3×3，按时间顺序）。

本文分三部分：视频讲的思路（按原视频顺序）、和本项目 video2rig 的逐项对照、待办。

---

## 一、要解决的问题

- 人形角色有动捕库（Mixamo 等），AI 有大量真人动作可学；龙、巨魔这类怪物没有任何动作数据库，所以也没有现成工具。
- 目标：**任何怪物、任何动作，一个工具，不手工修帧。**

## 二、走过的弯路（为什么都不行）

| 尝试 | 做法 | 失败原因 |
|---|---|---|
| 代码写关键帧 | Opus 直接用代码给鹿写走路 | 动作僵硬，不像真动物 |
| 视频轮廓匹配 | 给自己的模型生成 AI 视频，逐帧摆姿势、渲染、比对轮廓 | ① 侧面看腿一直交叉，分不清哪条腿（近/远腿混淆），只能让 Opus 逐帧手标；② 视频是平的，深度只能猜，像素级吻合但 3D 明显错 |
| 两个视频分别拍正面和侧面 | — | Seedance 同样输入两次会给出两个不同视频，正侧面永远对不上 |
| **一张图里放两个机位**（正面＋侧面） | 交给 Seedance 一张含两个机位的参考图 | 深度问题解决了（两条射线交于一点）。但脚本报 "84% 匹配"，打开对照画面大部分帧是坏的，又得 Opus 逐帧修 → 一只巨魔要 4 天＋大量 token，不可持续 |
| Google DeepMind 点跟踪 | 首帧是自己渲染的，知道每个像素属于哪 | 几步之后腿上的点滑到身体上，腿上没点了 |
| Meta SAM 2 轮廓分割 | 每条腿一个轮廓 | 走路还行；跑起来腿模糊，远侧腿消失或跳到胸口，前后腿颜色串 |
| Depth Anything（单图深度） | 用深度区分近/远腿 | 近腿远腿给出同样的深度，只有 4/10 帧判对；两腿只差 10 厘米，太小 |
| 给腿涂不同颜色（像袜子） | Seedance 保留了颜色，几乎每帧都能分清 | 完全依赖 Seedance 每次都保留颜色（不保证）；4 条腿 4 种颜色还行，龙的翅膀、6 肢半人马就不够用 |
| 动物姿态检测器 | 用几千张真实动物照片训练 | 侧面把远侧腿画在肚子上，正面一团乱 |
| MoCapAnything | 用真实动物动捕训练 | 狼原地跑，奔跑不到位；而且只适用于动物，不适用于怪物 |

**结论**：通用模型都没见过"我们的怪物"，靠它们找关节注定失败。

## 三、最终方案

### 核心思路

> 如果两个机位都准确知道某个关节在画面里的位置，3D 就是简单的数学：两条射线一交，完事。
> 所以整个问题只剩一件事：**在每一帧、两个画面里找到每个关节，并且知道哪个是哪个。**

### 流程（每只怪物一次性准备，之后每个动作只需几分钟）

1. **模型**：Tripo 生成 3D 模型。
2. **骨架**：用 UniRig（AI 自动在 3D 模型里画骨头）。效果"好但不完美"：会有骨头伸出身体，甚至没有腿。
   - **跑 4 次，按规则挑最好的一次**：每条着地的腿都必须有骨头；左右必须对称。
   - **手指并入手掌**；**裁掉伸出身体的骨头**。
3. **参考图**：同一张图里放正面＋侧面两个机位，发给 Seedance 当首帧生成动作视频。
4. **识别器**：拿 Meta 的 DINO（见过上百万张图），只教它一件新事：找这一只怪物的每个关节。
   - 用这只怪物渲染 **3000 个随机姿势，两个机位都拍**；因为是自己渲染的，每个关节的准确位置都已知。
   - **故意做难**：约一半姿势是快速动作，四肢带运动模糊（Seedance 就是这样的）。
   - 每张训练图：随机弯曲每个关节，**但只弯到真实关节能弯的程度** → 转动身体 → 快速部分加模糊 → **再故意弄差一点，模仿 Seedance**（光线、颜色、模糊的手臂）。
   - 训练约 30 分钟（RTX 4070）。
   - 识别结果按左（橙）/右（蓝）/中线（白）三种颜色显示。
5. **考试**（每只怪物，包括全新的）：
   - 自己编一段动作：每个关节随机动，**但只在关节限制范围内**。
   - 用同样两个机位在同一摄影棚里拍。因为动作是自己编的，每帧每个关节的位置都已知。
   - 工具像读 Seedance 视频一样读它，**逐骨骼**和标准答案对比。
   - 新蜥蜴在花钱生成任何 Seedance 视频之前就先考了试。
   - **工具的每次改动都必须让每只怪物通过考试，否则撤掉。**
6. **视频检查**：Seedance 视频进来之前先查——**左右两个画面是不是同一个动作？** Seedance 有时会在两半画出不同动作，这种情况直接重新生成视频比修更快。
7. **读视频 → 套到骨架 → 导出**到 Blender 和游戏里。

### 关于深度的补充实验

- 他们也教了自己的识别器预测深度（渲染时每个关节的深度已知）。
- 同一段狼奔跑：自己的识别器每一帧都判对近/远腿；Depth Anything 只有 4/10。
- **但和两个机位结合后几乎没有改变**——两个机位本身已经看得到深度。
- 能不能用"单机位＋深度"代替第二个机位？**还不行**：它知道哪条腿更近，但不知道具体有多远。

### 视频承认的局限

- 如果 Seedance 在两个画面里画了不同的动作，工具只能跟其中一个。
- 被身体挡住的手仍然是猜的。

### 效果

- 之前：一只巨魔 4 天，Opus 逐帧验证，大量 token。
- 现在：几分钟。学习过程每只怪物只做一次，之后想做什么动画都行。
- 支持四足、两足、翅膀、尾巴、**手持武器（半人马一直握着剑）**。

## 四、与本项目 video2rig 的对照

### 已经一致的

| 视频要点 | 本项目对应 |
|---|---|
| 一张图两个机位，射线相交得 3D | `prepare` 生成 `reference_two_views.png`；`solve.py` 三角测量 |
| 3000 随机姿势、两机位、约一半带运动模糊 | `gen_poses.py`（`fast_frac=0.5`，EEVEE 运动模糊） |
| 模仿 Seedance 弄差训练图 | `data.py`：背景、阴影、灰尘、色偏、模糊、噪声、缩放、JPEG |
| DINO 识别器，按左/右/中线 | `model.py` / `train.py`（DINOv2 ViT-B/14），关键点带 side/mirror |
| 关节只弯到真实范围 | 2026-11-03 起默认**按关节类型的解剖角度限制**（`common.py` `anatomical_limits()`），旧版固定范围用 `--generic-limits` |
| 编动作考试、逐骨骼对比 | `exam.py`；2026-11-03 起按骨骼真实长轴评分，扭转单独报告，`--regrade` 可只重评 |
| 检查两画面是否同一动作 | `solve.py` `consistency_report`，不通过为 `NEEDS_REVIEW` |
| 手指并入手掌、裁掉伸出身体的骨尖 | `extract_rig` 的 `min_seg_frac` 折叠和射线裁剪 |
| 深度识别帮助有限 | 已有深度头实验（`work/analyze/depth/`），结论一致 |

### 本项目额外做的（视频没提）

- 3ds Max 类 FBX 的身体网格挂在骨骼下、没有骨骼变形且转了 90°：导入时自动重新绑定（`rebind_bone_parented_skins`）。
- 和父骨骼共用起点的辅助骨骼（`*_Bone`）自动跟随父骨骼。
- 实验版时序解算器 `--solver temporal`：去抖。m11101 实测手臂抖动降 74%，快动作保留约 90% 速度。

### 视频里有、本项目还没做到的

1. **武器挂在手上**（最直接相关）
   - 视频：半人马全程握剑，剑跟着手动。
   - 本项目：兔子的枪放在脚边，是不会动的部件，导出的动画里枪留在地上。
   - 模型本身已有挂点：`Weapon_R_slot` / `prop_r_slot` 挂在 `Bip001 R Hand`，`Weapon_L_slot` / `prop_l_slot` 挂在 `Bip001 L Hand`，枪上有 `25101_slot`。
   - 做法：prepare 时按挂点把枪装到手上，让参考图、训练图、导出动画里枪都跟手走。代价：做不了"从地上捡枪"。
2. **每次改动都让每只怪物重考**
   - 视频的规矩：改动不过考就撤掉。
   - 本项目 2026-11-03 的"按关节类型限制""辅助骨骼跟随"只在 m11101 上考过；lizard、dog 还没用新默认设置重跑。
   - 已知问题：dog_v2 骨架是竖着的，会被误判成两足，需要加手动指定体型（两足/四足）的选项。
3. **自动骨架多次生成择优**
   - 视频：UniRig 跑 4 次，按"着地腿都有骨头、左右对称"挑最好的。README 中注明尚未自动化。
   - m11101 自带骨架暂用不上；但"左右对称"可用来检查现有骨架——m11101 左大腿考试误差 20.8°、右大腿约 8°，不对称，值得查。
