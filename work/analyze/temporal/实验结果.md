# 可信度融合＋联合时序求解：第一轮实验

2026-11-02。默认仍为 legacy；新增 temporal 为可选实验模式。未重训、未改检查阈值、未加自动接触；所有旧动画保留。

## 实现

- 观测权重：图像边界、热图峰值/多峰/局部峰宽、按秒窗口的留一稳健线性轨迹预测创新、投影骨骼边异常、温和且对称的双视角射线因子。
- 无可见性预测头；所有权重是启发式而非概率。射线偏差不能单独判哪一视角错误。
- 热图、深度随左右身份交换同步重排（仅新路径），原 API 兼容。
- 联合优化根旋转、局部旋转、世界关键点加速度与根部位置加速度；旋转项是相对旋转矩阵增量的弦长加速度代理，非欧拉角二阶差分。
- 加速度乘 fps²，平方损失相应 fps⁴，按时间平均；热图统计在 CPU 上计算以减少 GPU 峰值分配。
- 保留 legacy warm-start；实验路径 warm-start 的加速度项也使用 fps 归一化。没有使用 GT 初始化。
- 后段 LBFGS 联合精修减少优化器自身的迭代残留；未使用 stable 后滤波。

## 固定 GT、连续时间噪声的跨帧率测试

同一2秒动作以24/30/60fps采样；全局Slerp、局部Euler插值→FK；连续时间噪声及单视离群脉冲相同。baseline均匀权重0.9，temporal fused无热图时中性回退。固定seed/输入hash见JSON。

带噪声结果：

| fps | legacy关节误差% | temporal关节误差% | legacy骨角° | temporal骨角° | legacy根/局部角加速度 rad/s² | temporal根/局部角加速度 rad/s² |
|---|---:|---:|---:|---:|---|---|
|24|0.130|0.156|1.058|1.143|3.834 / 25.626|1.775 / 21.344|
|30|0.128|0.161|1.059|1.147|4.233 / 26.303|1.796 / 21.581|
|60|0.132|0.190|1.101|1.554|7.884 / 52.683|1.871 / 22.300|

**明确退化**：temporal平均位置和角误差略增；24/60共同时间网格位置轨迹差约0.025%→0.086%，没有全面改善跨帧率一致性。
归一化让加速度尺度更接近，但更强的平滑、局部最优/暖启动和GT非C²插值会引入误差；不能宣称帧率无关。
均匀权重消融与fused结果接近，说明当前轻噪声试验尚未证明权重融合带来额外收益。legacy基线只匹配warm预算，temporal另有refinement+polish，计算预算非等额，报告包含此限制。

## 检查

- 12项观测权重测试、2项旋转损失解析/梯度测试、2项热图与metadata重排集成测试、2项拒绝诊断回归通过。
- FBX/GLB回读：头关节点最大坐标误差约4.1e-6/2.1e-6单位；骨方向向量误差均<5.5e-6。导入器重建叶骨长度，尾点不能直接用旧tail_len检验。
- Web默认legacy，可选temporal；实验输出禁止覆盖已有motion；xiyi经网页仍为needs_review。
