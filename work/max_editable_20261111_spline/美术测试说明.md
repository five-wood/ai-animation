# 美术测试说明：m11101 spline 可编辑版（2026-11-11）

**文件**：[spline_edit.max](spline_edit.max)（3ds Max 2026，0–150 帧，30fps）。也可在 Max 中 Scripting → Run Script 运行 `video2rig/tools/max2026/V2R_Max2026.ms`，点第一个按钮打开。

**请另存为自己的文件再改**，不要覆盖本文件、`base_scene.max` 或原始角色 `11101_01(10.22).max`。打开时弹出的 Scene Converter（mental ray / BonesPro 缺失）先关闭，不要转换或删除缺失资源。

## 这一版的结构

| 部位 | 节点 | 关键帧（姿势键 + 过渡键） |
|---|---|---|
| 双脚 | `Bip001 L/R Foot` | 第 0 帧 + 第 150 帧，**planted IK**，全程锁在地面同一点 |
| 腿 | Thigh / Calf | 不打腿部 FK 键，由 Biped IK 根据脚与重心解算 |
| 重心 | `Bip001`（COM） | 4 + 6 |
| 躯干/头 | Spine、Spine1、Neck、Head | 9 + 8 |
| 左臂 | Clavicle → Hand | 10 + 13 |
| 右臂 | Clavicle → Hand | 14 + 21 |
| 左耳 / 右耳 | Bone001… / Bone0013… | 3 + 3 / 6 + 6 |
| 尾巴 | Bone004 | 7 + 6 |

- 所有键都在整数帧上；每两个姿势键之间有 1–3 个过渡键。
- 各部位的键时间互相独立：改手臂不需要碰躯干或腿的键。
- `Bip001 Pelvis` 没有动画键，骨盆的运动已合并到 COM 上，这是 Biped 的正常用法。
- 整体比原拟合低约 0.67cm，这是为了让双腿始终保持弯曲，避免锁脚时膝盖伸直卡死。

## 请帮忙试这三件事

每项完成后请记录：大约用时、改了几个键、有没有需要额外修的地方。

1. **加深下蹲（只改重心）**
   - 选中 `Bip001`（COM，不是 Pelvis），打开 Auto Key，跳到第 90 帧，把 COM 向下移 1–2cm，关闭 Auto Key 后回放。
   - 预期：脚不离地、不滑动，膝盖自然多弯一些。我们在 Max 里用脚本做过同样的修改（第 90 帧下移 1.5cm），双脚漂移小于 0.001mm，膝盖从约 46–58° 变成约 56–71°。
   - 注意：不要把 COM 抬高到腿伸直以上，那样脚会被拉离地面。
2. **改右臂抬手的姿势**
   - 在第 70–120 帧举手的区间内，选一个右臂姿势键，调整 UpperArm / Forearm / Hand。
   - 看相邻过渡键是否还顺：如果出现鼓包或抖动，需要改几个过渡键？
3. **改节奏**
   - 在 Track View 或时间轴上把右臂第 63–72 帧的抬手键整体往后拖，或把间隔拉开，看动作是否自然。

## 已知问题（请反馈是否影响使用）

- **左肘全程伸直**：原拟合的左肘只弯 1–11°，而且多数帧是向 Biped 肘关节转不过去的方向弯，所以合法化后左肘保持伸直。右肘正常，弯曲 0–71°。
- **手臂位置与原拟合有差距**：手和小臂相对原拟合最多差约 1.7–1.8cm，多数时候不超过约 1.1–1.4cm。原因一部分是 Biped 锁骨不能扭转、肘部只能单轴弯曲，一部分是稀疏化。手腕位置基本没变（差 0.3cm 以内）。
- **脚是我们手动定为全程站立的**：原拟合里脚有 1–2cm 的漂移，我们判断是拟合误差，所以锁在中位位置。如果视频里实际有挪步，请告诉我们。
- 本版只处理了这段 5 秒的原地片段；换步、单脚、跳跃还没有覆盖。
