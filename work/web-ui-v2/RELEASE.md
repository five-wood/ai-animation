# video2rig Web 第二批改进

## 范围

- 统一任务观测：Web 队列与受支持 CLI 命令；CLI 只读，不接管或取消。
- 真实阶段：实际命令子进程或新鲜日志，明确分子/分母才显示阶段进度；不估算全流程百分比或 ETA。
- 生成闭环：本页任务卡、完成/诊断跳转、失败载入参数重新核对；新名称不覆盖旧结果，危险确认不恢复，不自动重试。
- 项目性能：摘要缓存、元数据仅保留计数、JSONL 增量读取、启动预热、前端请求合并与缓存。
- 安全限制：同项目任务冲突在后端拦截；外部 CLI 在运行时队列等待；观测不可用时不启动新计算任务。
- 现有算法未提交改动不纳入发布。仅更新 Web Python 模块和不可变静态入口。

## 验证

- 项目缓存：7 项 stdlib 测试通过。
- 任务观测：28 项模拟 proc/log 测试通过，无进程/GPU 启动。
- 生成页：25 项隔离测试通过。
- 路由：4 项测试通过；结果预览与任务 UI 测试通过。
- 服务器现有环境：原有接口 12 项、新任务安全接口 6 项通过；临时数据、禁用工作器，无真实计算任务。
- 只读性能预检：原项目接口约 4.9 秒；新摘要首次解析约 6.3 秒（启动预热），缓存读取约 0.04 秒 / 0.0001 秒。统一任务冷读约 0.9 秒、缓存约 0.002 秒。实际 HTTP 性能需上线后再测。
- 发布只在授权的空闲条件执行：两次确认 Web 队列与 CLI 观测均空闲；发现任务则停止，不取消任务。

## 发布方式

`video2rig/tools/stage_web_batch.py` 打包隔离验证副本；`video2rig/tools/package_web_ui.py` 打包静态资源。`video2rig/tools/deploy_web_batch.py` 校验当前入口/后端 SHA256、静态资源清单和空闲状态后，只切换 Web 文件并重启服务。运维备份在公共静态目录之外，用于发布失败回退，不保留额外旧版公共入口。

### 故障回退说明（仅在再次确认无任务后执行）

只恢复 Web 文件，不回退训练数据或队列。需先把非公开备份的 `previous-static` 复制回原静态版本目录，再恢复备份 `server.py` 与 `index.html`，最后重启一次 Web 服务；恢复前应检查当前任务与进程，不能在计算中直接执行。备份记录 `record.json` 给出前一入口摘要与哪些模块原本存在。新增监控模块可以暂留但不会被旧服务引用。

## 当前边界

- CLI 观测限已知代码根下的受支持调用，不是全系统调度器；进程消失仅记“结束，结果待核实”，外部历史为内存一小时。
- 日志过旧、缺失或命令未给总量时显示阶段但不伪造百分比。
- 不能阻止另一个操作者绕过 Web 在稍后启动冲突 CLI 写入，仍需避免外部并发修改同一项目。
- 失败恢复本批仅动画参数复核；训练阶段断点恢复、模型版本化、新建角色分步预览留待后续。
- 不为界面验收启动真实训练/动画任务。端到端计算验收应另选测试项目明确进行。
